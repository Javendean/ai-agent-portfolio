3. THE DISPROOF -- an arithmetically perfect, semantically wrong mapping
  expected: conservation PASSES, sign preservation PASSES, and ONLY the oracle fails.

  OK  expect_table_aggregation_to_equal_other_table   want PASS   got PASS
  OK  assert_sign_preservation                        want PASS   got PASS
  OK  assert_subtotal_oracle                          want FAIL   got FAIL

  what the oracle saw, and nothing else could:
      E1 2026-05 gross_profit: off by -309,245.88
      E1 2026-06 gross_profit: off by -323,912.13
      E1 2026-07 gross_profit: off by -206,319.81

Both accounts are debit-normal and the row is assigned exactly once, so the entity still ties to the cent. Gross profit is wrong by $309,245.88

Only the oracle catches it, because it compares reconstructed captions against subtotals the entity itself published from its own chart — a classification made before any group chart existed, which the mapper never reads. An independent oracle, not a tighter tolerance.

3 · LCC Management System — a deployment I own end to end

What it does

SvelteKit · Supabase/Postgres · Vercel · Twilio

Contact management, segmentation and bilingual (EN/ES) SMS campaigns for a non-profit — ~10 admin users, ~350 contacts. Real users, real regulatory exposure.

  • Compliance as architecture. TCPA opt-outs are never deleted; re-subscribing sets a timestamp so the original opt-out time survives, which is the value regulators ask for. Every send path filters on active opt-outs.
  • A cost bug caught by a test. Spanish templates force UCS-2 encoding (67 chars per segment vs GSM-7's 153). One template was 3 segments in ES and 1 in EN — ~2× cost per campaign. Fixed, then locked behind a segment-budget test.
  • Governed access. New accounts require explicit admin approval; no self-serve signup.

Deployed and auth-gated

lcc-management-system.vercel.app/login

Production deployment on Vercel. Every route redirects to authentication — this is as far as an unauthenticated visitor gets, by design. Contact and message data is deliberately not reproduced here.
